THE NOMADIC BARBER — WEBSITE FILES
==================================

WHAT'S HERE
  index.html            → your website (open this to preview locally)
  media/song.mp3        → background music
  media/clip.mp4        → your interview clip (Watch section)
  media/clip-poster.jpg → the clip's thumbnail frame

Keep index.html and the "media" folder together. Don't rename them.

PUBLISH FREE ON NETLIFY
  1. Go to netlify.com and sign up (free).
  2. "Add new site" → "Deploy manually".
  3. Drag THIS WHOLE FOLDER onto the drop area.
  4. It goes live at a temporary address like yourname.netlify.app.

CONNECT YOUR DOMAIN (thenomadicbarber1.com)
  1. In Netlify: Domain management → Add a custom domain → thenomadicbarber1.com
  2. Netlify gives you 4 nameservers (like dns1.p0X.nsone.net ...).
  3. In GoDaddy: My Products → thenomadicbarber1.com → DNS → Nameservers → Change
     → "I'll use my own nameservers" → paste the 4 Netlify nameservers → Save.
  4. Wait 15 min–a few hours. Netlify adds free HTTPS (the padlock) automatically.

AFTER IT'S LIVE
  You can cancel any GoDaddy HOSTING / Website Builder plan — but KEEP the
  domain registration (that's your address).

UPDATING LATER
  To change the site, get a new index.html and drag the folder onto Netlify
  again (or set up drag-and-drop redeploys). Send changes to me anytime.
